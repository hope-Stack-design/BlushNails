# Campus Blush & Bloom - Client Scheduling & Portfolio Web App

A lightweight, responsive web application designed for a localized, student-run beauty venture at Kenyatta University. The application serves as both a visual service portfolio and a live, static appointment scheduling system.

🔗 **Live Project:**  https://hope-stack-design.github.io/BlushNails/

## Features
- **Dynamic Slot Availability:** Real-time scheduling layout allowing users to view open, pending, and booked slots dynamically.
- **WhatsApp API Integration:** Custom-configured form handling that sanitizes user input and automatically formats appointment data into a pre-filled WhatsApp messaging link for zero-friction client confirmation.
- **Mobile-First Responsive Design:** Optimized specifically for mobile browsers, ensuring fast loading speeds on low-bandwidth campus data networks.

## Tech Stack
- **Frontend:** Semantic HTML5, CSS3 (Custom Flexbox layout, no heavy frameworks to ensure instant loading times).
- **Automation:** Native JavaScript (DOM Manipulation, WhatsApp URI encoding).
- **Hosting & Deployment:** GitHub Pages.

## Real-World Impact
- Successfully deployed to serve a student community of thousands within the university area.
- Reduced appointment booking friction by streamlining scheduling down to 3 clicks, minimizing manual booking administrative time.
